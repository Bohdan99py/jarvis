# Скиллы J.A.R.V.I.S. / J.A.R.V.I.S. Skills

Скилл — это папка со знаниями, которую JARVIS подключает как лего-блок.
Никакой компиляции: манифест + markdown-файл со знаниями.

```
skills/
  my_skill/
    skill.json   — манифест
    prompt.md    — знания (попадают в system prompt, когда скилл включён)
```

## skill.json

```json
{
    "id": "my_skill",
    "name":        { "ru": "Мой скилл", "en": "My Skill" },
    "description": { "ru": "Что умеет", "en": "What it does" },
    "version": "1.0.0",
    "features": [],
    "default_enabled": false
}
```

- `id` — уникальное имя (латиница, без пробелов). Совпадает с именем папки.
- `features` — нативные возможности ядра, которые включает скилл.
  Сейчас поддерживается `"code_actions"` — IDE-агент (применение
  [FILE]/[DIFF]/[CMD] блоков из ответов). Обычным скиллам-знаниям
  оставьте пустой список.
- `default_enabled` — включён ли скилл сразу после установки.

## Куда класть

- Пользовательские скиллы: `Документы/Jarvis Data/skills/<id>/`
  (или через меню Настройки → Скиллы → Импортировать скилл).
- Скиллы из этой папки устанавливаются вместе с JARVIS и при первом
  запуске копируются к пользователю, где их можно править и удалять.

Управление: **Настройки → Скиллы JARVIS** — включение/выключение на лету,
без перезапуска.
