## Что нового / What's New

### 🏷️ Последние релизы
- **v3.0.1** — 2026-06-10

### 🔄 Последние изменения

**🗄️ База данных**
- Добавлена SQLite БД (DatabaseManager) — история чатов, команды, память, настройки
- Таблицы: `chat_history`, `commands`, `memory_kv`, `settings`, `indexed_files`, `behavior_patterns`
- WAL режим, thread-safe соединения, система миграций

**📚 Обучение**
- BackgroundLearner — фоновая индексация `.cpp/.h/.py` файлов игрового проекта
- Анализ истории чатов → паттерны поведения пользователя
- Запускается автоматически при старте, повторяет цикл каждые 30 минут

**🧠 ИИ / AI**
- VoiceInput — голосовой ввод через Whisper.cpp
- Поддержка шёпота (порог -45 dB, temperature=0 для стабильности)
- VAD (Voice Activity Detection) без внешних библиотек
- Автоопределение языка RU/EN без переключения
- Wake word «Джарвис» / «Jarvis»
