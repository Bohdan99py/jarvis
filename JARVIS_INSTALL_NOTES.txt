WHAT'S NEW IN VERSION 3.x
--------------------------
  * Voice model selection dialog on first launch
  * Support for 6 languages: EN (fast/full), RU, DE, FR, ZH
  * Download and remove models from Settings -> Voice
  * All Vosk DLLs included in installer — internet only needed
    to download language models (your choice)
  * Recording only on voice activity (VAD) — silence is ignored

FIRST LAUNCH
-------------
  1. On first launch, a "Voice Input Setup" dialog will appear.
  2. Select the languages you need. Start with "English — Fast" (40 MB).
  3. Click "Install" — JARVIS will download and configure models automatically.
  4. Once done, say "Jarvis" — you're good to go!

If you skipped the dialog or want to add languages later:
  Settings -> Voice -> Voice Models -> [Download]


VOICE MODELS (specs)
---------------------
  English Fast      ~40 MB    Commands, wake word. Instant load.
  English Full    ~1.8 GB     Dictation, transcription. High quality.
  Russian         ~1.8 GB     Full RU/EN switching support.
  Deutsch         ~1.0 GB     German.
  Francais        ~1.0 GB     French.
  Chinese           ~500 MB   Chinese (small model).

Models are stored in: %APPDATA%\Bohdan99py\JARVIS\vosk\
Remove a model: Settings -> Voice -> [Delete] next to the model.


WAKE WORD (activation)
-----------------------
Say "Jarvis" to activate. You can speak a command right after:
  "Jarvis, open the browser"
  "Jarvis, what time is it?"


VOICE COMMANDS
---------------
Examples:
  "Jarvis, open Telegram"             — launch an app
  "Jarvis, search Google for [query]" — browser search
  "Jarvis, take a screenshot"         — screen capture
  "Jarvis, show the weather"          — weather forecast
  "Jarvis, remind me in 30 minutes"   — timer/reminder
  "Jarvis, what's open right now?"    — list windows
  "Jarvis, shut down the computer"    — power management


SETTINGS
---------
  Voice -> Voice Models        — manage models
  Voice -> Silence Threshold   — mic sensitivity (-45 dB default)
  Voice -> Language            — auto / fixed language
  AI -> API Key                — Claude API key (for complex queries)
  General -> Autostart         — launch with Windows


PRIVACY & SECURITY
-------------------
  * Voice recognition runs LOCALLY — no cloud servers.
  * Microphone activates only when sound exceeds VAD threshold (-45 dB).
    Silence is never recorded or processed.
  * Audio is never saved to disk — kept in RAM during recognition only.
  * Data never leaves your computer (except Claude/Gemini API requests
    if configured).
  * API keys are stored encrypted.

Details: PRIVACY_POLICY.txt in the installation folder.


SYSTEM REQUIREMENTS
--------------------
  OS:         Windows 10/11 x64
  RAM:        4 GB minimum (8 GB recommended with large models)
  Disk:       200 MB for the app + space for models
  Microphone: any Windows-compatible (USB, built-in, Bluetooth)
  Internet:   only needed for downloading models and Claude/Gemini API


TROUBLESHOOTING
----------------
  Microphone not picking up sound:
    -> Check permissions: Start -> Settings -> Privacy -> Microphone
    -> Try a different mic or increase volume in Windows

  Wake word not triggering:
    -> Settings -> Voice -> Silence Threshold: slide toward -60 dB
    -> Make sure a model is downloaded (green indicator in main window)

  "Models not loaded" error:
    -> Settings -> Voice -> Voice Models -> select and download a model
    -> Check folder: %APPDATA%\Bohdan99py\JARVIS\vosk\

  Slow model loading on startup:
    -> Large models (RU, EN Full) take 5-15 sec — this is normal.
    -> Use "English Fast" for instant startup.
