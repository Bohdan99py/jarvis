КРАТКОЕ РЕЗЮМЕ (TL;DR)
───────────────────────
• Голосовой ввод работает ЛОКАЛЬНО — интернет не нужен для распознавания.
• Микрофон включается АВТОМАТИЧЕСКИ при запуске голосового ввода,
  но запись активируется ТОЛЬКО при обнаружении звука выше порога VAD.
• Аудиоданные не сохраняются на диск и не отправляются на серверы.
• Claude / Gemini API: текстовые запросы отправляются в облако
  ТОЛЬКО для обработки ИИ-запросов — НЕ аудио.
• Никакой телеметрии, аналитики, рекламы.


1. ГОЛОСОВОЙ ВВОД И ЗАПИСЬ МИКРОФОНА
──────────────────────────────────────

1.1. АВТОМАТИЧЕСКАЯ АКТИВАЦИЯ
   J.A.R.V.I.S. использует НЕПРЕРЫВНОЕ прослушивание микрофона (wake-word mode)
   при включённом голосовом вводе. Это означает:
   - После команды «Запустить голосовой ввод» / нажатия кнопки в UI
     программа ПОСТОЯННО анализирует аудиопоток с микрофона.
   - Анализ выполняется ЛОКАЛЬНО на вашем устройстве.
   - Полная ЗАПИСЬ (буферизация для распознавания) начинается только
     когда уровень звука превысит порог VAD (по умолчанию -45 dB).

1.2. ЧТО ЗАПИСЫВАЕТСЯ
   - Только фрагменты с голосовой активностью (речь, громкие звуки).
   - Тишина и фоновый шум ниже порога VAD НЕ записываются и НЕ обрабатываются.
   - Запись хранится в оперативной памяти только во время обработки (~1–15 сек).
   - После распознавания аудиобуфер немедленно освобождается.

1.3. ЧТО НЕ ДЕЛАЕТСЯ С АУДИО
   - Аудио НЕ сохраняется в файлы на диске.
   - Аудио НЕ передаётся на внешние серверы.
   - Аудио НЕ используется для обучения моделей.
   - История разговоров хранится как ТЕКСТ (транскрипт), не как аудио.

1.4. УПРАВЛЕНИЕ ГОЛОСОВЫМ ВВОДОМ
   Вы можете в любой момент:
   - Выключить голосовой ввод: кнопка 🎤 в главном окне / команда «Стоп».
   - Отозвать разрешение на микрофон: Настройки Windows → Конфиденциальность
     → Микрофон → J.A.R.V.I.S.
   - Удалить установленные голосовые модели: Settings → Голос → [Удалить].


2. ГОЛОСОВЫЕ МОДЕЛИ
────────────────────

2.1. Модели Vosk скачиваются с серверов alphacephei.com / Hugging Face
     ТОЛЬКО по вашему явному запросу (диалог первого запуска или Settings).

2.2. После скачивания модели работают ПОЛНОСТЬЮ ОФЛАЙН.
     Интернет для распознавания не требуется.

2.3. Модели хранятся в: %APPDATA%\Bohdan99py\JARVIS\vosk\
     Вы можете удалить их вручную или через Settings.


3. ИИ-ЗАПРОСЫ (Claude / Gemini API)
────────────────────────────────────

3.1. ТОЛЬКО ТЕКСТ отправляется в API Claude (Anthropic) и Gemini (Google).
     Аудио никогда не передаётся в облако.

3.2. Запросы отправляются только когда JARVIS обращается к ИИ для ответа
     (код, сложные вопросы, анализ). Системные команды выполняются локально.

3.3. Содержимое запросов подчиняется политикам конфиденциальности Anthropic
     и Google соответственно:
     - Anthropic: https://www.anthropic.com/privacy
     - Google:    https://policies.google.com/privacy

3.4. API-ключи хранятся в реестре Windows в зашифрованном виде и никуда
     не передаются, кроме соответствующих API-серверов.


4. ЛОКАЛЬНЫЕ ДАННЫЕ
────────────────────

4.1. История чатов (SQLite, локально):
     %APPDATA%\Bohdan99py\JARVIS\jarvis.db
     Хранит текстовые диалоги. Не покидает устройство.

4.2. Голосовой журнал (voice_journal):
     Текстовые транскрипты голосовых сессий. Только локально.

4.3. Настройки:
     Реестр Windows: HKCU\Software\Bohdan99py\JARVIS

4.4. Для удаления всех данных:
     - Удалите приложение через «Программы и компоненты» Windows.
     - Папку %APPDATA%\Bohdan99py\JARVIS можно удалить вручную
       (модели и история не удаляются автоматически при деинсталляции).


5. СЕТЕВАЯ АКТИВНОСТЬ
──────────────────────

J.A.R.V.I.S. обращается к сети ТОЛЬКО для:
  ✓ Скачивания голосовых моделей (alphacephei.com) — по запросу пользователя
  ✓ Запросов к Claude API (api.anthropic.com) — при работе с ИИ
  ✓ Запросов к Gemini API (generativelanguage.googleapis.com) — при работе с ИИ
  ✓ Проверки обновлений (github.com/Bohdan99py/jarvis) — при запуске

JARVIS НЕ обращается к сети для:
  ✗ Телеметрии и аналитики
  ✗ Рекламы
  ✗ Передачи аудио
  ✗ Синхронизации данных

ENGLISH SUMMARY

J.A.R.V.I.S. Privacy Policy — Key Points:

VOICE RECORDING:
  The microphone is continuously monitored while voice input is active.
  However, audio is only CAPTURED (buffered) when sound exceeds the
  Voice Activity Detection threshold (-45 dB by default).
  Silence is never recorded. Audio is never saved to disk or sent to servers.
  All speech recognition runs locally via Vosk (offline AI).

AI REQUESTS:
  Only TEXT is sent to Claude API / Gemini API — never audio.
  Requests are made only when you ask JARVIS to use AI for complex tasks.

LOCAL DATA:
  Chat history and voice transcripts are stored locally in SQLite.
  No telemetry, analytics, or advertising.

You can disable the microphone at any time via the 🎤 button.
