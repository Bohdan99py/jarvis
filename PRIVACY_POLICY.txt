===================================================================
   J.A.R.V.I.S. — Privacy Policy
   Version 3.1 · 2026
===================================================================

TL;DR
------
  * Voice input runs LOCALLY — no internet needed for recognition.
  * Microphone activates automatically when voice input is started,
    but audio is only CAPTURED when sound exceeds the VAD threshold.
  * Audio is never saved to disk or sent to servers.
  * Claude / Gemini API: only TEXT is sent to the cloud
    for AI processing — NEVER audio.
  * No telemetry, analytics, or advertising.


1. VOICE INPUT AND MICROPHONE RECORDING
-----------------------------------------

1.1. AUTOMATIC ACTIVATION
   J.A.R.V.I.S. uses CONTINUOUS microphone monitoring (wake-word mode)
   when voice input is enabled. This means:
   - After enabling voice input via the UI button or command,
     the app CONTINUOUSLY analyzes the audio stream from the mic.
   - Analysis is performed LOCALLY on your device.
   - Full RECORDING (buffering for recognition) begins only when
     sound level exceeds the VAD threshold (default -45 dB).

1.2. WHAT IS RECORDED
   - Only segments with voice activity (speech, loud sounds).
   - Silence and background noise below the VAD threshold are
     NOT recorded and NOT processed.
   - Recordings are kept in RAM only during processing (~1-15 sec).
   - After recognition, the audio buffer is immediately released.

1.3. WHAT IS NOT DONE WITH AUDIO
   - Audio is NOT saved to files on disk.
   - Audio is NOT transmitted to external servers.
   - Audio is NOT used to train models.
   - Conversation history is stored as TEXT (transcript), not audio.

1.4. CONTROLLING VOICE INPUT
   You can at any time:
   - Disable voice input: microphone button in the main window
     or say "Stop".
   - Revoke microphone permission: Windows Settings -> Privacy
     -> Microphone -> J.A.R.V.I.S.
   - Delete installed voice models: Settings -> Voice -> [Delete].


2. VOICE MODELS
----------------

2.1. Vosk models are downloaded from alphacephei.com / Hugging Face
     ONLY at your explicit request (first-launch dialog or Settings).

2.2. Once downloaded, models work FULLY OFFLINE.
     No internet required for recognition.

2.3. Models are stored in: %APPDATA%\Bohdan99py\JARVIS\vosk\
     You can delete them manually or via Settings.


3. AI REQUESTS (Claude / Gemini API)
--------------------------------------

3.1. ONLY TEXT is sent to Claude API (Anthropic) and Gemini API (Google).
     Audio is never transmitted to the cloud.

3.2. Requests are sent only when JARVIS calls the AI for a response
     (code, complex questions, analysis). System commands run locally.

3.3. Request content is subject to the privacy policies of Anthropic
     and Google respectively:
     - Anthropic: https://www.anthropic.com/privacy
     - Google:    https://policies.google.com/privacy

3.4. API keys are stored encrypted in the Windows registry and are
     never transmitted anywhere except the corresponding API servers.


4. LOCAL DATA
--------------

4.1. Chat history (SQLite, local):
     %APPDATA%\Bohdan99py\JARVIS\jarvis.db
     Stores text conversations. Never leaves the device.

4.2. Voice journal (voice_journal):
     Text transcripts of voice sessions. Local only.

4.3. Settings:
     Windows Registry: HKCU\Software\Bohdan99py\JARVIS

4.4. To delete all data:
     - Uninstall the app via Windows "Apps & Features".
     - The folder %APPDATA%\Bohdan99py\JARVIS can be deleted manually
       (models and history are not removed automatically on uninstall).


5. NETWORK ACTIVITY
---------------------

J.A.R.V.I.S. connects to the network ONLY for:
  [Y] Downloading voice models (alphacephei.com) — at user request
  [Y] Claude API requests (api.anthropic.com) — for AI processing
  [Y] Gemini API requests (generativelanguage.googleapis.com) — for AI
  [Y] Checking for updates (github.com/Bohdan99py/jarvis) — on launch

JARVIS does NOT connect for:
  [N] Telemetry or analytics
  [N] Advertising
  [N] Audio transmission
  [N] Data synchronization
